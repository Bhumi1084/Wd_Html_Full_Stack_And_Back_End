Q-1 : What are the benefits of using CSS?

=> CSS (Cascading Style Sheets) provides numerous benefits for web development, including:

1. Separation of Content and Design:
    -> This makes it easier to maintain and update the look and feel of a website without altering the underlying HTML structure.

2. Consistency:
    -> By defining styles in a single CSS file, you can ensure a consistent look across multiple web pages. Any changes made to the CSS file will be reflected across all linked pages, promoting a uniform design.

3. Improved Load Times:
    -> CSS files are cached by browsers, which can reduce page load times after the initial load. This is because the browser doesn’t have to re-download the CSS file for every page load.

4. Enhanced Accessibility:
    -> Proper use of CSS can improve the accessibility of a website. For example, it can provide better control over how content is presented on different devices, including screen readers used by visually impaired users.

5. Greater Design Flexibility:
    -> CSS provides a wide range of styling options, including colors, fonts, layouts, animations, and more. This allows for more creative and visually appealing designs compared to inline styling or older methods like tables for layout.

6. Reduced HTML File Size:
    -> By moving styling information to CSS files, HTML documents become cleaner and smaller. This simplifies the HTML code, making it more readable and easier to maintain.

7. Responsive Design:
    -> CSS allows for responsive web design, which adapts the layout of a website to different screen sizes and devices. Media queries and flexible grid layouts make it possible to create sites that look good on both desktops and mobile devices.

8. Ease of Maintenance:
    -> Centralized style management means that updates to the website’s design can be made in one place (the CSS file) rather than in multiple HTML files. This simplifies the process of making site-wide design changes.

9. Better Performance:
    -> External CSS files can be downloaded once and cached by the browser, leading to better overall performance and reduced bandwidth usage.

10. Professional Appearance:
    -> Using CSS can contribute to a more professional and polished appearance of a website, enhancing the user experience and potentially increasing user engagement and satisfaction.
