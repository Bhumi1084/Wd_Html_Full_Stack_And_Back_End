Q-19 : What is the rule set? 

-> In CSS, a rule set (or CSS rule) defines how a set of styles should be applied to selected HTML elements.

-> It consists of two main components: the selector and the declaration block.

-> Components of a Rule Set : Selector, Declaration Block

-> Example of a Rule Set:
    h1 {
        color: red;
        font-size: 24px;
        text-align: center;
    }

-> A CSS rule set is a fundamental concept in styling web pages. It consists of:

-> Selector: Specifies which HTML elements the styles apply to.

-> Declaration Block: Contains one or more declarations that define the styles for the selected elements.
