Q-17 : What is the meaning of the CSS selector?

-> A CSS selector is a pattern used in CSS to target and apply styles to HTML elements based on their attributes, 
    relationships, or other characteristics. 
-> Selectors specify which elements in a web page the styles should be applied to.

=> Types of CSS Selectors:
1. Universal Selector:
-> Syntax: *    
-> Description: Selects all elements on the page.
-> Example:
    * {
        margin: 0;
        padding: 0;
    }

2. Type Selector:
-> Syntax: element
-> Description: Selects all elements of a specific type
-> Example:
    p {
        color: blue;
    }

3. Class Selector:
-> Syntax: .classname
-> Description: Selects all elements with a specific class attribute.
-> Example:
    .highlight {
        background-color: yellow;
    }

4. ID Selector:
-> Syntax: #idname
-> Description: Selects a single element with a specific ID attribute. IDs must be unique within a page.
-> Example:
    #header {
        font-size: 24px;
    }

5. Attribute Selector:
-> Syntax: [attribute=value]
-> Description: Selects elements based on the presence or value of an attribute.
-> Example:
    [type="text"] {
        border: 1px solid #ccc;
    }

6. Descendant Selector:
-> Syntax: ancestor descendant
-> Description: Selects elements that are descendants of a specified ancestor element.
-> Example:
    .container p {
        color: green;
    }

7. Child Selector:
-> Syntax: parent > child
-> Description: Selects elements that are direct children of a specified parent element.
-> Example:
    ul > li {
        list-style-type: none;
    }

8. Adjacent Sibling Selector:
-> Syntax: element1 + element2
-> Description: Selects an element that is immediately preceded by a specified element.
-> Example:
    h2 + p {
        margin-top: 0;
    }

9. General Sibling Selector:
-> Syntax: element1 ~ element2
-> Description: Selects all elements that are siblings of a specified element.
-> Example:
    h2 ~ p {
        color: red;
    }

10. Pseudo-class Selector:
-> Syntax: :pseudo-class
-> Description: Selects elements based on their state or position.
-> Example:
    a:hover {
        color: orange;
    }

11. Pseudo-element Selector:
-> Syntax: ::pseudo-element
-> Description: Selects and styles part of an element.
-> Example:
    p::first-line {
        font-weight: bold;
    }
