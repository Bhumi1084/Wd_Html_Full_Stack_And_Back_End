Q-2 : What are the disadvantages of CSS?

=> While CSS offers many advantages, it also comes with some disadvantages:

1. Browser Compatibility:
    -> Different browsers and even different versions of the same browser may render CSS differently. This inconsistency can lead to issues in ensuring a uniform appearance across all platforms.

2. Complexity for Large Projects:
    -> As a website grows, the CSS can become increasingly complex and harder to manage. Without proper organization, such as using CSS preprocessors or methodologies (like BEM or SMACSS), maintaining the styles can become challenging.

3. Global Scope:
    -> CSS rules are global by default, which can lead to unintended side effects. For instance, a style defined for one element might inadvertently apply to another, causing unexpected behavior.

4. Lack of Variables and Functions (Prior to CSS3):
    -> Before CSS3 introduced variables, CSS lacked the ability to store values and reuse them, leading to repetitive code. Although CSS preprocessors like SASS or LESS addressed this, native support was limited.

5. Cascading Issues:
    -> The cascading nature of CSS can be both a benefit and a drawback. It can sometimes lead to conflicts and overriding issues where specific styles might not behave as intended due to the order and specificity of other styles.

6. Limited Design Control:
    -> While CSS provides many design options, there are still some limitations compared to more robust graphical design tools. Achieving very complex designs might require additional workarounds or reliance on other technologies like JavaScript.

7. Dependency on HTML Structure:
    -> CSS often depends on the HTML structure, meaning changes to the HTML can necessitate changes to the CSS. This tight coupling can make redesigns more labor-intensive.

8. Performance Issues:
    -> Improperly written CSS can lead to performance issues. For example, using overly general selectors or having too many nested rules can slow down the rendering of the page.

9. Learning Curve:
    -> While CSS is relatively easy to start with, mastering advanced concepts like flexbox, grid, animations, and responsive design can have a steep learning curve.

10. Debugging Difficulties:
    -> Debugging CSS issues can be challenging, especially when dealing with complex layouts and multiple overlapping rules. It often requires significant trial and error to pinpoint and resolve styling problems.
