Q-3 : What is the difference between CSS2 and CSS3?

=> Modular Structure:
    -> CSS2: A single, monolithic specification.
    -> CSS3: Divided into multiple modules, each focusing on a specific aspect of CSS. 

=> New Selectors:
    -> CSS2: Limited set of selectors, mainly focusing on basic types like class, ID, and element selectors.
    -> CSS3: Introduced advanced selectors, such as attribute selectors, pseudo-classes, and pseudo-elements.

=> Media Queries:
    -> CSS2: Basic support for media types.
    -> CSS3: Introduced media queries, allowing for responsive design by applying styles based on device characteristics like width, height, and orientation.

=> Box Model Enhancements:
    -> CSS2: Standard box model with limitations on layout flexibility.
    -> CSS3: New layout models, such as the Flexible Box Layout and Grid Layout, providing more powerful and flexible ways to create complex layouts.

=> Animation and Transitions:
    -> CSS2: No native support for animations or transitions.
    -> CSS3: Added animations and transitions, allowing for smoother and more dynamic visual effects without relying on JavaScript.

=> Borders and Backgrounds:
    -> CSS2: Basic support for borders and backgrounds.
    -> CSS3: Enhanced features, including border-radius, multiple background images, background-size, background-clip, and more.

=> User Interface Enhancements:
    -> CSS2: Limited user interface styling options.
    -> CSS3: New user interface properties, such as box-sizing, resize, and appearance.
