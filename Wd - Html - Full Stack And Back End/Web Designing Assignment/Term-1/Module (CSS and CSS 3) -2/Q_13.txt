Q-13 : What are the ways to integrate CSS as a web page?

=> There are three ways to integrate CSS as a web page.

1. Inline CSS:
    -> Apply styles directly within HTML elements using the style attribute. This method is useful for quick styling or overriding other styles but is not ideal for maintaining large stylesheets.
    Example :
        <p style="color: blue; font-size: 16px;">This is an inline-styled paragraph.</p>

2. Internal CSS:
    -> Define styles within a <style> element inside the <head> section of your HTML document. This method is good for styles that are specific to a single page.
    Example :
        <!DOCTYPE html>
        <html lang="en">
            <head>
                <meta charset="UTF-8">
                <meta name="viewport" content="width=device-width, initial-scale=1.0">
                <title>Internal CSS Example</title>
                <style>
                    body {
                        background-color: #f0f0f0;
                        font-family: Arial, sans-serif;
                    }
                    .container {
                        width: 80%;
                        margin: 0 auto;
                    }
                    .text-blue {
                        color: blue;
                    }
                </style>
            </head>
            <body>
                <div class="container">
                    <p class="text-blue">This is a paragraph with internal CSS.</p>
                </div>
            </body>
        </html>

3. External CSS:
    -> Link to an external CSS file using the <link> element in the <head> section. This is the preferred method for larger projects as it promotes reusability and separation of concerns.
-> Example:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>External CSS Example</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <div class="container">
    <p class="text-blue">This is a paragraph with external CSS.</p>
  </div>
</body>
</html>

-> styles.css:
body {
  background-color: #f0f0f0;
  font-family: Arial, sans-serif;
}
.container {
  width: 80%;
  margin: 0 auto;
}
.text-blue {
  color: blue;
}
