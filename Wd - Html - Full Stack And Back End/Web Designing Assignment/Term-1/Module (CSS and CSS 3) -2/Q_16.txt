Q-16 : What are the advantages and disadvantages of using external style sheets? 

=> Using external style sheets comes with several advantages and disadvantages. 

1) Advantages of Using External Style Sheets:

    -> Separation of concerns for better organization and maintainability.

    -> Reusability across multiple HTML documents.

    -> Maintainability

    -> Performance benefits from browser caching and reduced redundancy.
    
    -> Scalability for larger projects with shared styles.

2) Disadvantages of Using External Style Sheets:

    -> Initial Loading Time

    -> Dependency on correct file paths and network availability.

    -> Increased complexity for small projects.

    -> Possible CSS specificity conflicts.
