Q-8 : What is the use of the background-position property?

-> The background-position property in CSS is used to specify the initial position of a background image within its container.

-> It defines where the background image is placed relative to the element it is applied to.

-> The property can take various values, including keywords, length values, percentages, and a combination of these.

-> Here are the main ways to use the background-position property:
    1) Top Left
    2) Top Right
    3) Bottom Left
    4) Bottom Right
    5) Center

-> Example:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Background Position Examples</title>
  <style>
    .example {
      width: 200px;
      height: 200px;
      background-image: url('path/to/image.jpg');
      border: 1px solid #000;
      margin-bottom: 10px;
    }
    .example1 { background-position: top left; }
    .example2 { background-position: top right; }
    .example3 { background-position: bottom left; }
    .example4 { background-position: bottom right; }
    .example5 { background-position: center; }
    .example6 { background-position: 50px 100px; }
    .example7 { background-position: 50% 50%; }
    .example8 { background-position: top 50%; }
    .example9 { background-position: bottom 20px; }
  </style>
</head>
<body>
  <div class="example example1">top left</div>
  <div class="example example2">top right</div>
  <div class="example example3">bottom left</div>
  <div class="example example4">bottom right</div>
  <div class="example example5">center</div>
  <div class="example example6">50px 100px</div>
  <div class="example example7">50% 50%</div>
  <div class="example example8">top 50%</div>
  <div class="example example9">bottom 20px</div>
</body>
</html>
