Q-6 : How can the background color of an element be changed?

-> The background color of an element can be changed using the background-color property in CSS. 

-> This property allows you to set the background color of an HTML element. 

-> You can specify the color using various formats, including named colors, hexadecimal values, RGB values, RGBA values, HSL values, and HSLA values. 

-> Here are examples of how to use each format:

-> Example :
    <!DOCTYPE html>
    <html lang="en">
        <head>
            <meta charset="UTF-8">
            <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <title>Background Color Examples</title>
            <style>
            .example1 {
                background-color: blue;
                color: white; /* Text color for contrast */
                padding: 10px;
            }
            .example2 {
                background-color: #ff0000;
                color: white;
                padding: 10px;
            }
            .example3 {
                background-color: rgb(0, 255, 0);
                color: black;
                padding: 10px;
            }
            .example4 {
                background-color: rgba(0, 0, 255, 0.5);
                color: white;
                padding: 10px;
            }
            .example5 {
                background-color: hsl(120, 100%, 50%);
                color: black;
                padding: 10px;
            }
            .example6 {
                background-color: hsla(240, 100%, 50%, 0.5);
                color: white;
                padding: 10px;
            }
            </style>
        </head>
        <body>
            <div class="example1">Named Color (Blue)</div>
            <div class="example2">Hexadecimal Color (#ff0000)</div>
            <div class="example3">RGB Color (rgb(0, 255, 0))</div>
            <div class="example4">RGBA Color (rgba(0, 0, 255, 0.5))</div>
            <div class="example5">HSL Color (hsl(120, 100%, 50%))</div>
            <div class="example6">HSLA Color (hsla(240, 100%, 50%, 0.5))</div>
            </body>
    </html>
